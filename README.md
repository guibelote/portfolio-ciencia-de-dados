# Portfólio de Ciência de Dados

Olá! Este repositório reúne projetos selecionados de estudo em Ciência de Dados, com foco em análise exploratória, Python, estatística, visualização e aprendizado de máquina.

> **Status:** portfólio em desenvolvimento. Os projetos abaixo são estudos práticos; estou revisando os notebooks, resultados, referências e instruções de execução antes de considerá-los finalizados.

## Projetos

| Projeto | Tema | Tecnologias | Status |

| [Análise de desempenho de estudantes](projects/01-analise-desempenho-estudantes/) | EDA, estatística e visualização; experimento de regressão | Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn | Em revisão |

## Competências demonstradas

- Limpeza, transformação e exploração de dados com Pandas.
- Estatística descritiva e análise de relações entre variáveis.
- Visualização de dados e comunicação de resultados.
- Fundamentos de regressão e avaliação de modelos.
- Noções de coleta de dados via web scraping.

## Como executar

Use Python 3.10 ou 3.11. Para começar, crie um ambiente virtual e instale as dependências do projeto que deseja executar. Cada pasta contém instruções específicas.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```
