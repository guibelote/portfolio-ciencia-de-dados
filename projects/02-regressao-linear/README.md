# Regressão linear na prática

## Objetivo
Demonstrar, com um pequeno conjunto de dados definido no próprio notebook, como calcular os coeficientes de uma reta, interpretar resíduos e comparar o cálculo manual com o ajuste por OLS.

## Tecnologias
Python, Pandas, NumPy, Matplotlib e statsmodels.

## Executar
Abra `regressao_linear.ipynb` no Jupyter e execute as células na ordem.

- [ ] Executar o notebook e corrigir avisos ou APIs antigas.
- [ ] Explicar o significado do coeficiente angular, intercepto e R².
- [ ] Verificar se os cálculos de SQT, SQE e SQR usam definições consistentes.
