# Análise de desempenho de estudantes

## Objetivo
Explorar os resultados de matemática, leitura e escrita e investigar como as notas se relacionam com variáveis categóricas presentes na base. O notebook também contém um experimento introdutório de regressão para estimar a nota de matemática.

## Dados
Dataset *Students Performance in Exams*, publicado no Kaggle: https://www.kaggle.com/datasets/spscientist/students-performance-in-exams. Consulte a página original para os termos de uso e atribuição.

## Tecnologias
Python, Pandas, NumPy, Matplotlib, Seaborn e scikit-learn.

## Executar
Na raiz desta pasta, abra `analise_desempenho_estudantes.ipynb` no Jupyter. Instale as dependências listadas no `requirements.txt` da raiz do portfólio.
